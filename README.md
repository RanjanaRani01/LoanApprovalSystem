# 🏦 Loan Approval Prediction System

A Machine Learning-based web application that predicts whether a loan will be approved or not based on applicant details such as income, credit score, loan amount, and loan history.

## 🚀 Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Scikit-learn

## 📌 Features

* Loan approval prediction
* User-friendly interface
* Random Forest Classifier
* Real-time prediction
* Model accuracy display

## 📂 Files

* `app.py` → Main Streamlit application
* `loan_approval.csv` → Dataset
* `README.md` → Project documentation

## ▶️ Run the Project

Install required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
streamlit run app.py
```

## 🤖 Machine Learning Model

* Random Forest Classifier

## 📊 Input Features

The user needs to enter:

Age
Gender
Income
Loan Amount
Home Ownership
Loan Intent
Interest Rate
Credit History
Credit Score
Previous Loan Defaults

After clicking the Predict Loan Status button, the system predicts whether the loan will be approved or rejected.
